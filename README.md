# Нам хорошо вместе

Telegram-бот и сопутствующие документы для оценки совместимости на основе модели «Нам хорошо вместе».

## Возможности версии 1.0
- двухэтапный тест для друзей, пар и коллег (руководство/подростки учитываются отдельными формулировками);
- локализация на русском и английском языках;
- красочный текстовый отчёт с прогнозом исходов («долго и счастливо» и др.);
- встроенный AI-компаньон, который использует результаты теста и базу знаний модели;
- добровольная обратная связь для улучшения вопросника и рекомендаций.

## Быстрый старт
1. Создайте виртуальное окружение и установите зависимости:
   ```bash
   python -m venv .venv
   source .venv/bin/activate
   pip install -e .
   ```
2. Укажите токен Telegram-бота и путь к хранилищу (по умолчанию `./var/bot.sqlite`):
   ```bash
   export BOT_TOKEN="<ваш_токен>"
   export BOT_STORAGE="./var/bot.sqlite"  # необязательно
   ```
3. Запустите бота:
   ```bash
   python -m bot.main
   ```

> **Важно:** бот использует SQLite для хранения сессий. Для production-среды предусмотрено перенесение схемы в PostgreSQL (см. `bot/storage.py`).

## Структура репозитория
- `bot/` — исходный код Telegram-бота и сервисных модулей.
- `compatibility_program_plan.md` — описание модели, план версий и сценарии.
- `technical_documentation.md` — живой документ со всеми архитектурными решениями и статусом работ.
- `description of the psychological compatibility model.txt` — первоисточник модели.
